# 坦克大战游戏 (Tank Battle)

一个使用纯HTML5 Canvas开发的经典坦克大战游戏。

## 游戏特性

- 🎮 经典的坦克对战玩法
- 🎯 流畅的坦克控制和射击机制
- 🤖 智能AI敌方坦克
- 💥 爆炸特效和视觉反馈
- 📈 逐级增加的难度系统
- ❤️ 生命值系统
- 🏆 得分和等级系统

## 游戏控制

### 键盘控制
- **WASD** 或 **方向键** - 控制坦克移动
- **空格键** - 发射子弹
- **R** - 重新开始游戏
- **P** - 暂停/继续游戏

### 按钮控制
- **开始游戏** - 开始新游戏
- **暂停** - 暂停/继续游戏
- **重新开始** - 重新开始当前游戏

## 游戏规则

1. 控制绿色坦克（玩家）对抗红色敌方坦克
2. 消灭所有敌方坦克进入下一关
3. 每一关敌方坦克数量会增加
4. 玩家有3点生命值，被击中会减少生命值
5. 消灭敌方坦克获得100分，过关获得500分奖励
6. 每过一关会恢复1点生命值（最多3点）

## 技术实现

- **HTML5 Canvas** - 游戏渲染
- **原生JavaScript** - 游戏逻辑
- **CSS3** - UI样式和动画
- **面向对象编程** - 游戏实体管理

### 主要类
- `Tank` - 坦克基类，包含玩家和敌方坦克
- `Bullet` - 子弹类
- `Explosion` - 爆炸效果类

## 如何运行

1. 克隆或下载项目
2. 在浏览器中打开 `index.html` 文件
3. 点击"开始游戏"按钮开始游戏

## 在线试玩

直接在浏览器中打开即可游玩，无需额外配置。
